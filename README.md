# animalkaiserRoblox
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0.

## Getting Started

Gameplay code lives in `src/` and is synced into Studio with Rojo. `AGENTS.md`
contains the current project specification. Progress is session-only.

The lobby, stalls, and map are edited in Studio and are not included in the Rojo
build below. Preserve a Studio place save separately; `tools/build-lobby.luau`
updates the existing lobby but does not recreate all imported scenery from scratch.
To build the place from scratch, use:

```bash
rojo build -o "animalkaiserRoblox.rbxlx"
```

Next, open `animalkaiserRoblox.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
